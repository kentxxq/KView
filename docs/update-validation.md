## 更新模块与插件故障验证

临时验证程序直接包含项目现有 `updates.rs` 和错误类型，使用原更新命令及 Tauri Updater 插件。故障仅在测试进程中注入，不修改正式源码或线上清单。各场景共执行 86 次断言（包含重复的初始状态与互斥检查），全部通过。

| 范围 | 已验证行为 |
| --- | --- |
| 前置条件与互斥 | 未检查不能下载、未下载不能安装；并发检查、重复下载和下载期间安装被拒绝 |
| 版本比较 | 同版本及更高客户端不更新；同版本或更旧的清单不触发更新 |
| 检查失败 | 连接拒绝、20 秒超时、非 JSON 内容、404、缺少目标平台均返回错误；除超时外均额外验证可再次检查 |
| 下载失败与重试 | 非 HTTPS 地址被应用拒绝；下载连接失败后恢复正确地址，可以重新下载并进入待安装状态 |
| 签名与完整性 | 错误公钥、损坏签名、单字节篡改、截断包、签名版本与清单不一致均被拒绝；错误公钥场景可重新发起下载 |
| 缓存与安装前保护 | 已下载更新不重复下载，也不被后续检查覆盖；安装前再次发现包损坏时恢复操作状态并保留包，允许重试 |
| 清单解析 | 无效结构、非法版本、缺少平台均被拒绝 |
| 传输边界 | 未知总长度时累计字节并完成验签；流传输中断时返回错误 |

传输边界使用插件层的本地 HTTP 夹具提供正式签名包或中途截断的响应，只验证插件的分块读取与验签。应用层拒绝 HTTP 更新地址的行为另行验证；没有关闭 TLS 校验或改变系统网络、安全设置。安装失败恢复采用缓存包篡改触发安装前验签失败，没有人为破坏系统安装器。

## 本轮没有覆盖的边界

- macOS arm64/x64 实机安装、升级、Applications 权限及 Gatekeeper：当前环境只有 Windows，构建成功不等于实机验收通过。
- 连续等待 6 小时触发定时检查、开发模式不自动检查：本轮仅核对实现，未进行长时间驻留或开发模式运行。
- 真实下载尚未结束时关闭并重建窗口：本轮验证的是下载完成后的待安装状态恢复，传输中断另在插件层验证。
- 文件打开、保存和关闭与安装同时发生的所有竞态、安装期间的全部输入阻止：没有完成桌面端逐项竞态注入。
- Windows 已有文件关联的升级迁移，以及系统安装器自身失败、磁盘满和权限拒绝：本轮没有预先注册关联或改变系统环境来构造这些故障。
- 签名私钥离线备份：属于运维保管状态，本轮未读取私钥或验证外部备份。
